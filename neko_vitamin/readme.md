# 🐱 Neko Vitamin

Веб-приложение для проверки совместимости витаминов и минералов (по таблице Роскачества)
и составления программы приёма с добавлением в календарь.

## Как пользоваться

1. Отметить витамины и минералы → **Проверить**.
2. Посмотреть совместимость пар и варианты приёма. Выбрать подходящий вариант (щелчок по карточке).
3. В блоке **«Программа приёма»** задать время каждого приёма, дату начала, длительность курса
   (дни / недели / месяцы) и за сколько минут напоминать.
4. Добавить в календарь:

| Способ | Повтор каждый день | Напоминание |
|---|---|---|
| **Добавить в Google Календарь** → появляются кнопки «➕ Утром / ➕ Вечером …», каждая открывает готовое событие, нажать «Сохранить» | ✅ | поставить вручную в окне события (Google не принимает его через ссылку) |
| **Скачать файл .ics** | ✅ | ✅ на телефоне, в Outlook, Apple Календаре; Google Календарь при импорте (Настройки → Импорт) может поставить своё стандартное |

## Как устроено

- Все данные (список веществ и пары из таблицы) — в начале `<script>` в `index.html`:
  `ITEMS`, `GOOD` (зелёные точки), `BAD` (красные точки). Их же можно взять для Android-приложения.
- Расписание = раскраска графа: несовместимые вещества не попадают в один приём,
  число приёмов минимальное; из вариантов выбираются те, где больше полезных пар
  и вещества стоят в удобное время (B-витамины и железо утром, кальций, магний, цинк вечером).
- Каждый приём — отдельное повторяющееся событие (`RRULE:FREQ=DAILY;COUNT=<дней курса>`)
  длительностью 15 минут.

> Учебный проект. Не является медицинской рекомендацией — дозировки и курс назначает врач.

§26 Соли, их классификация и свойства

Задание 1 — классификация

Распределите соли на три группы — средние, кислые и основные: NaCl, NaHCO₃, CaCO₃, Ca(H₂PO₄)₂, (CuOH)₂CO₃, K₂SiO₃, ZnOHCl, Ba(NO₃)₂.

Средние — полное замещение водорода на металл. Кислые — содержат водород (H). Основные — содержат гидроксогруппу (OH).

Средние: NaCl, CaCO₃, K₂SiO₃, Ba(NO₃)₂.
Кислые: NaHCO₃, Ca(H₂PO₄)₂.
Основные: (CuOH)₂CO₃, ZnOHCl.

Задание 2 — названия

Дайте названия солям: KNO₂, Al(NO₃)₃, FeCl₃, K₂SO₃, CuSO₄, FeS, Ca₃(PO₄)₂, Na₂SiO₃.

Название = название кислотного остатка + название металла в родительном падеже (+валентность, если переменная).

KNO₂ — нитрит калия; Al(NO₃)₃ — нитрат алюминия; FeCl₃ — хлорид железа(III); K₂SO₃ — сульфит калия; CuSO₄ — сульфат меди(II); FeS — сульфид железа(II); Ca₃(PO₄)₂ — фосфат кальция; Na₂SiO₃ — силикат натрия.

Задание 3 — растворимость

Из перечня выберите формулы солей и определите их растворимость в воде: NiCl₂, LiOH, POCl₃, SiH₄, Pb(NO₃)₂, Fe₂(SO₄)₃, SCl₄, CaSO₄, Ba₃(PO₄)₂, CuSO₄, Sn(NO₃)₂.

Соли = металл + кислотный остаток. Памятка: все нитраты растворимы; фосфаты нерастворимы; CaSO₄ малорастворим.

Соли: NiCl₂ (раств.), Pb(NO₃)₂ (раств.), Fe₂(SO₄)₃ (раств.), CaSO₄ (малораств.), Ba₃(PO₄)₂ (нераств.), CuSO₄ (раств.), Sn(NO₃)₂ (раств.).
Не соли: LiOH (основание), POCl₃, SiH₄, SCl₄.

Задание 4 — взаимодействие с металлами

Запишите уравнения реакций солей с металлами: а) сульфата меди(II) CuSO₄ с железом Fe; б) нитрата серебра AgNO₃ с медью Cu.

Металл вытесняет другой металл из соли, если он стоит ЛЕВЕЕ в ряду активности.

а) Fe + CuSO₄ = FeSO₄ + Cu (железо левее меди)
б) Cu + 2AgNO₃ = Cu(NO₃)₂ + 2Ag (медь левее серебра)

Задание 5 — взаимодействие с солями

Запишите уравнения реакций между растворами солей (признак — выпадение осадка): а) хлорида кальция CaCl₂ и карбоната натрия Na₂CO₃; б) хлорида бария BaCl₂ и сульфата натрия Na₂SO₄.

а) CaCl₂ + Na₂CO₃ = CaCO₃↓ + 2NaCl
б) BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl

Задание 6 — пять способов получить соль

Запишите уравнения пяти разных реакций, с помощью которых можно получить сульфат цинка ZnSO₄.

Вспомните 10 способов получения солей: кислота+металл, кислота+оксид, кислота+основание, основный оксид+кислотный оксид, металл+неметалл и т.д.

1) Zn + H₂SO₄ = ZnSO₄ + H₂↑ (металл + кислота)
2) ZnO + H₂SO₄ = ZnSO₄ + H₂O (оксид + кислота)
3) Zn(OH)₂ + H₂SO₄ = ZnSO₄ + 2H₂O (основание + кислота)
4) ZnO + SO₃ = ZnSO₄ (основный + кислотный оксид)
5) ZnCl₂ + Ag₂SO₄ = ZnSO₄ + 2AgCl↓ (соль + соль)

Задание 7 — расчётная

К 62,4 г 5%-ного раствора хлорида бария BaCl₂ добавили избыток раствора сульфата натрия Na₂SO₄. Рассчитайте массу выпавшего осадка.

BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl. Найдите m(BaCl₂), n(BaCl₂), по уравнению n(BaSO₄), затем m(BaSO₄).

m(BaCl₂)=62,4·0,05=3,12 г. M(BaCl₂)=208. n(BaCl₂)=3,12/208=0,015 моль. n(BaSO₄)=0,015 моль. M(BaSO₄)=233. m(BaSO₄)=0,015·233≈3,5 г.

Задание 8 — расчётная

Достаточно ли 50 мл 10%-ной соляной кислоты (плотность 1,05 г/мл) для полного растворения кусочка мела (карбонат кальция) массой 5 г?

CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑. Найдите n(CaCO₃) и n(HCl), сравните с учётом коэффициентов (на 1 моль CaCO₃ нужно 2 моль HCl).

n(CaCO₃)=5/100=0,05 моль → нужно 0,1 моль HCl.
m(р-ра HCl)=50·1,05=52,5 г. m(HCl)=52,5·0,1=5,25 г. n(HCl)=5,25/36,5≈0,144 моль.
0,144 > 0,1 — кислоты достаточно (даже с избытком).

§27 Генетическая связь между классами

Задание 9 — классификация простых веществ

Распределите простые вещества на три класса (металлы, неметаллы, благородные газы): Na, Cl₂, He, Fe, S, Ne, Al, P, Ca, Ar.

Металлы: Na, Fe, Al, Ca.
Неметаллы: Cl₂, S, P.
Благородные газы: He, Ne, Ar.

Задание 10 — генетический ряд металла

Запишите уравнения реакций для генетического ряда металла (которому соответствует щёлочь): Li → Li₂O → LiOH → Li₂SO₄.

Генетический ряд металла: металл → основный оксид → основание → соль.

4Li + O₂ = 2Li₂O
Li₂O + H₂O = 2LiOH
2LiOH + H₂SO₄ = Li₂SO₄ + 2H₂O

Задание 11 — генетический ряд неметалла

Запишите уравнения реакций для генетического ряда неметалла: P → P₂O₅ → H₃PO₄ → Ag₃PO₄.

Генетический ряд неметалла: неметалл → кислотный оксид → кислота → соль.

4P + 5O₂ = 2P₂O₅
P₂O₅ + 3H₂O = 2H₃PO₄
H₃PO₄ + 3AgNO₃ = Ag₃PO₄↓ + 3HNO₃

Задание 12 — цепочка с серой

Запишите уравнения реакций для цепочки превращений: S → X → H₂SO₃ → Na₂SO₃ → X. Определите вещество X.

X — это оксид серы(IV), SO₂. Он повторяется дважды в цепочке.

X = SO₂.
S + O₂ = SO₂↑
SO₂ + H₂O = H₂SO₃
H₂SO₃ + 2NaOH = Na₂SO₃ + 2H₂O
Na₂SO₃ + 2HCl = 2NaCl + H₂O + SO₂↑

Задание 13 — цепочка меди

Запишите уравнения реакций для генетического ряда меди (которому соответствует нерастворимое основание): Cu → CuO → CuSO₄ → Cu(OH)₂ → CuO → Cu.

2Cu + O₂ = 2CuO
CuO + H₂SO₄ = CuSO₄ + H₂O
CuSO₄ + 2NaOH = Cu(OH)₂↓ + Na₂SO₄
Cu(OH)₂ →(t) CuO + H₂O
CuO + H₂ →(t) Cu + H₂O

Задание 14 — определи X₁, X₂, X₃

В цепочке превращений Ca → X₁ → Ca(OH)₂ → X₂ → CaO → X₃ → AgCl определите вещества X₁, X₂, X₃ и запишите уравнения реакций.

X₁ — оксид кальция, X₂ — карбонат кальция, X₃ — хлорид кальция. Подберите реакции под каждый переход.

X₁=CaO, X₂=CaCO₃, X₃=CaCl₂.
2Ca + O₂ = 2CaO
CaO + H₂O = Ca(OH)₂
Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O
CaCO₃ →(t) CaO + CO₂↑
CaO + 2HCl = CaCl₂ + H₂O
CaCl₂ + 2AgNO₃ = 2AgCl↓ + Ca(NO₃)₂

Задание 15 — реакции с кислотой

Какие из перечисленных веществ взаимодействуют с соляной кислотой? Запишите уравнения возможных реакций: магний Mg, оксид меди(II) CuO, гидроксид меди(II) Cu(OH)₂, медь Cu, нитрат магния Mg(NO₃)₂, гидроксид железа(III) Fe(OH)₃, нитрат серебра AgNO₃, сульфид железа(II) FeS.

Реагируют: Mg, CuO, Cu(OH)₂, Fe(OH)₃, AgNO₃, FeS (не реагируют: Cu, Mg(NO₃)₂).
Mg + 2HCl = MgCl₂ + H₂↑
CuO + 2HCl = CuCl₂ + H₂O
Cu(OH)₂ + 2HCl = CuCl₂ + 2H₂O
Fe(OH)₃ + 3HCl = FeCl₃ + 3H₂O
AgNO₃ + HCl = AgCl↓ + HNO₃
FeS + 2HCl = FeCl₂ + H₂S↑

Задание 16 — реакции с щёлочью

Какие из перечисленных веществ взаимодействуют с гидроксидом натрия NaOH? Запишите уравнения возможных реакций, назовите продукты: оксид углерода(IV) CO₂, гидроксид кальция Ca(OH)₂, оксид меди(II) CuO, нитрат меди(II) Cu(NO₃)₂, хлорид аммония NH₄Cl, кремниевая кислота H₂SiO₃, сульфат калия K₂SO₄.

Реагируют: CO₂, Cu(NO₃)₂, NH₄Cl, H₂SiO₃.
CO₂ + 2NaOH = Na₂CO₃ + H₂O (карбонат натрия)
Cu(NO₃)₂ + 2NaOH = Cu(OH)₂↓ + 2NaNO₃ (гидроксид меди + нитрат натрия)
NH₄Cl + NaOH = NaCl + NH₃↑ + H₂O (хлорид натрия + аммиак)
H₂SiO₃ + 2NaOH = Na₂SiO₃ + 2H₂O (силикат натрия)

Вопрос 1

Средняя (нормальная) соль — это продукт:

Средние соли — продукты полного замещения атомов водорода в кислоте на металл (например, NaCl, CaCO₃).

Вопрос 2

NaHCO₃ — это соль:

NaHCO₃ содержит незамещённый атом водорода (H), поэтому это кислая соль (продукт неполного замещения водорода).

Вопрос 3

Какая соль нерастворима в воде?

BaSO₄ (сульфат бария) нерастворим. Все соли натрия и калия, а также все нитраты растворимы.

Вопрос 4

Реакция Fe + CuSO₄ = FeSO₄ + Cu возможна, потому что:

Железо вытесняет медь из раствора соли, так как стоит левее меди (активнее) в ряду активности металлов.

Вопрос 5

Признак реакции между растворами двух солей:

Реакция между растворами двух солей идёт, если образуется осадок. Например: CaCl₂ + Na₂CO₃ = CaCO₃↓ + 2NaCl.

Тест: §27 · Генетическая связь
Правильных ответов: 0 / 5

Вопрос 1

Генетическая связь — это связь между:

Генетической называется связь между веществами различных классов, связанных между собой взаимопревращениями.

Вопрос 2

Правильный порядок генетического ряда металла:

Генетический ряд металла: металл → основный оксид → основание → соль. Пример: Li → Li₂O → LiOH → Li₂SO₄.

Вопрос 3

Правильный порядок генетического ряда неметалла:

Генетический ряд неметалла: неметалл → кислотный оксид → кислота → соль. Пример: P → P₂O₅ → H₃PO₄ → Ag₃PO₄.

Вопрос 4

В цепочке S → SO₂ → H₂SO₃ → Na₂SO₃ вторая реакция (SO₂ → H₂SO₃) — это взаимодействие:

SO₂ + H₂O = H₂SO₃ — взаимодействие кислотного оксида с водой с образованием кислоты.

Вопрос 5

Какие простые вещества способны к аллотропии?

Многие неметаллы способны к аллотропии — образуют несколько простых веществ (например, кислород O₂ и озон O₃, разные формы углерода). Исключение — H, N и галогены.

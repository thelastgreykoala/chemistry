§23 Оксиды, их классификация и свойства

Задание 1

Распределите оксиды на три группы — основные, кислотные и несолеобразующие: Na₂O, SO₃, CO, P₂O₅, CaO, NO, N₂O₅, MgO, SiO₂, SiO.

Основные образованы металлами (валентность I–II), кислотные — неметаллами или металлами с высокой валентностью. Несолеобразующие: CO, NO, N₂O, SiO.

Основные: Na₂O, CaO, MgO.
Кислотные: SO₃, P₂O₅, N₂O₅, SiO₂.
Несолеобразующие: CO, NO, SiO.

Задание 2

Запишите формулы оксидов, соответствующих гидроксидам: а) серной кислоте H₂SO₄; б) марганцовой кислоте HMnO₄; в) гидроксиду железа(III); г) гидроксиду свинца(IV); д) хлорной кислоте HClO₄.

а) SO₃; б) Mn₂O₇; в) Fe₂O₃; г) PbO₂; д) Cl₂O₇.

Задание 3 — свойства оксидов

Запишите уравнения реакций: а) оксида кальция CaO с водой; б) оксида меди(II) CuO с серной кислотой; в) оксида серы(VI) SO₃ с гидроксидом натрия; г) основного оксида CaO с кислотным SiO₂ (при нагревании).

а) CaO + H₂O = Ca(OH)₂
б) CuO + H₂SO₄ = CuSO₄ + H₂O
в) SO₃ + 2NaOH = Na₂SO₄ + H₂O
г) CaO + SiO₂ →(t) CaSiO₃

Задание 4 — цепочка превращений

Запишите уравнения для цепочки: P → P₂O₅ → H₃PO₄ → Ca₃(PO₄)₂.

Сначала фосфор горит в кислороде, потом оксид реагирует с водой, потом кислота — с основанием или солью.

4P + 5O₂ = 2P₂O₅
P₂O₅ + 3H₂O = 2H₃PO₄
2H₃PO₄ + 3Ca(OH)₂ = Ca₃(PO₄)₂↓ + 6H₂O

Задание 5 — способы получения

Запишите три способа получения оксидов с примерами уравнений: а) взаимодействием простого вещества с кислородом; б) горением сложного вещества; в) разложением нерастворимого основания или соли.

а) 2Mg + O₂ = 2MgO (или S + O₂ = SO₂↑)
б) CH₄ + 2O₂ = CO₂↑ + 2H₂O (или 2ZnS + 3O₂ = 2ZnO + 2SO₂↑)
в) Fe(OH)₂ →(t) FeO + H₂O (или CaCO₃ →(t) CaO + CO₂↑)

Задание 6 — расчётная

Какой объём углекислого газа (н.у.) образуется при взаимодействии 730 г 20%-ной соляной кислоты с необходимым количеством мрамора CaCO₃? Какое количество вещества карбоната кальция потребуется?

CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑. Сначала найдите массу чистой HCl, затем n(HCl), затем по уравнению n(CO₂) и n(CaCO₃).

m(HCl)=730·0,2=146 г. n(HCl)=146/36,5=4 моль. По уравнению n(CO₂)=½·n(HCl)=2 моль. V(CO₂)=2·22,4=44,8 л. n(CaCO₃)=½·n(HCl)=2 моль.

§24 Основания, их классификация и свойства

Задание 7 — классификация

Классифицируйте основания по двум признакам (кислотность и растворимость): NaOH, Ca(OH)₂, Cu(OH)₂, KOH, Mg(OH)₂, Fe(OH)₃, Ba(OH)₂.

Кислотность — число групп OH. Растворимость определите по таблице растворимости (щёлочи — растворимые).

Однокислотные: NaOH, KOH. Двухкислотные: Ca(OH)₂, Cu(OH)₂, Mg(OH)₂, Ba(OH)₂. Трёхкислотное: Fe(OH)₃.
Растворимые (щёлочи): NaOH, KOH, Ca(OH)₂, Ba(OH)₂. Нерастворимые: Cu(OH)₂, Mg(OH)₂, Fe(OH)₃.

Задание 8 — реакция нейтрализации

Запишите уравнения реакций нейтрализации: а) гидроксида бария Ba(OH)₂ с азотной кислотой HNO₃; б) гидроксида железа(II) Fe(OH)₂ с соляной кислотой HCl.

а) Ba(OH)₂ + 2HNO₃ = Ba(NO₃)₂ + 2H₂O
б) Fe(OH)₂ + 2HCl = FeCl₂ + 2H₂O

Задание 9 — свойства щелочей

Запишите уравнения реакций щёлочи: а) гидроксида кальция Ca(OH)₂ с углекислым газом CO₂; б) гидроксида калия KOH с раствором сульфата меди(II) CuSO₄.

а) Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O
б) 2KOH + CuSO₄ = Cu(OH)₂↓ + K₂SO₄

Задание 10 — разложение оснований

Запишите уравнения разложения нерастворимых оснований при нагревании: а) гидроксида меди(II) Cu(OH)₂; б) гидроксида железа(II) Fe(OH)₂.

а) Cu(OH)₂ →(t) CuO + H₂O
б) Fe(OH)₂ →(t) FeO + H₂O

Задание 11 — цепочка превращений

Запишите уравнения для цепочки: Li → Li₂O → LiOH → Li₂CO₃ → CO₂.

4Li + O₂ = 2Li₂O
Li₂O + H₂O = 2LiOH
2LiOH + CO₂ = Li₂CO₃ + H₂O
Li₂CO₃ + 2HCl = 2LiCl + H₂O + CO₂↑

Задание 12 — расчётная

К 120 мл воды добавили 48 г раствора гидроксида натрия с массовой долей щёлочи 25%. Найдите массовую долю щёлочи в полученном растворе.

Найдите массу чистого NaOH в исходном растворе, затем общую массу нового раствора (вода + раствор).

m(NaOH)=48·0,25=12 г. m(нового р-ра)=120+48=168 г. ω(NaOH)=12/168·100%≈7,14%.

§25 Кислоты, их классификация и свойства

Задание 13 — классификация

Классифицируйте кислоты по наличию кислорода и основности: HCl, H₂SO₄, H₃PO₄, H₂S, HNO₃, H₂CO₃.

Наличие кислорода — есть ли O в формуле. Основность — число атомов водорода.

Кислородсодержащие: H₂SO₄, H₃PO₄, HNO₃, H₂CO₃. Бескислородные: HCl, H₂S.
Одноосновные: HCl, HNO₃. Двухосновные: H₂SO₄, H₂S, H₂CO₃. Трёхосновная: H₃PO₄.

Задание 14 — ряд активности

Используя ряд активности металлов, определите, какие металлы будут вытеснять водород из раствора соляной кислоты: Cu, Zn, Ag, Mg, Fe, Au. Запишите уравнение для одного из них.

Ряд активности: Li, K, Ca, Na, Mg, Al, Mn, Zn, Cr, Fe, ..., H, Cu, Hg, Ag, Au. Вытесняют водород металлы ЛЕВЕЕ H.

Вытесняют водород: Zn, Mg, Fe (стоят левее H). Не вытесняют: Cu, Ag, Au (правее H).
Например: Zn + 2HCl = ZnCl₂ + H₂↑.

Задание 15 — свойства кислот

Запишите уравнения реакций соляной кислоты HCl с: а) оксидом меди(II) CuO; б) гидроксидом натрия NaOH; в) карбонатом натрия Na₂CO₃.

а) CuO + 2HCl = CuCl₂ + H₂O
б) NaOH + HCl = NaCl + H₂O
в) Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑

Задание 16 — взаимодействие с разными классами

С какими из перечисленных веществ будет реагировать соляная кислота? Запишите уравнения возможных реакций: азот N₂, железо Fe, оксид кальция CaO, гидроксид алюминия Al(OH)₃, нитрат серебра AgNO₃.

Реагирует с Fe, CaO, Al(OH)₃, AgNO₃ (не реагирует с N₂).
Fe + 2HCl = FeCl₂ + H₂↑
CaO + 2HCl = CaCl₂ + H₂O
Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O
AgNO₃ + HCl = AgCl↓ + HNO₃

Задание 17 — получение кислот

Запишите уравнения получения: а) соляной кислоты HCl синтезом из простых веществ; б) серной кислоты H₂SO₄ из кислотного оксида; в) фосфорной кислоты H₃PO₄ из соли Ca₃(PO₄)₂ реакцией обмена с серной кислотой.

а) H₂ + Cl₂ = 2HCl
б) SO₃ + H₂O = H₂SO₄
в) Ca₃(PO₄)₂ + 3H₂SO₄ = 3CaSO₄↓ + 2H₃PO₄

Задание 18 — расчётная

На полную нейтрализацию 110 г раствора серной кислоты потребовалось 80 г 10%-ного раствора гидроксида натрия. Рассчитайте массовую долю кислоты в исходном растворе.

2NaOH + H₂SO₄ = Na₂SO₄ + 2H₂O. Найдите m(NaOH), n(NaOH), по уравнению n(H₂SO₄), затем m(H₂SO₄) и долю.

m(NaOH)=80·0,1=8 г. n(NaOH)=8/40=0,2 моль. По уравнению n(H₂SO₄)=½·n(NaOH)=0,1 моль. m(H₂SO₄)=0,1·98=9,8 г. ω=9,8/110·100%≈8,9%.

Тест: §23 · Оксиды
Правильных ответов: 0 / 5

Вопрос 1

Основные оксиды — это оксиды, которым в качестве гидроксидов соответствуют:

Основные оксиды взаимодействуют с кислотами, образуя соль и воду, и им соответствуют основания (например, CaO → Ca(OH)₂).

Вопрос 2

Какой из оксидов является кислотным?

SO₃ — кислотный оксид (образован неметаллом), ему соответствует серная кислота H₂SO₄. Остальные — основные оксиды металлов.

Вопрос 3

Несолеобразующий оксид — это:

CO (оксид углерода II) не взаимодействует ни с кислотами, ни со щелочами и не образует солей. Несолеобразующие: CO, NO, N₂O, SiO.

Вопрос 4

Какой оксид соответствует серной кислоте H₂SO₄?

Серной кислоте H₂SO₄ соответствует оксид серы(VI) — SO₃ (валентность серы VI в обоих соединениях).

Вопрос 5

Реакция CaO + SiO₂ →(t) CaSiO₃ показывает, что:

CaO (основный) и SiO₂ (кислотный) — солеобразующие оксиды, они взаимодействуют друг с другом, образуя соль (силикат кальция).

Тест: §24 · Основания
Правильных ответов: 0 / 5

Вопрос 1

По числу гидроксогрупп основание Ca(OH)₂ является:

В Ca(OH)₂ две гидроксогруппы (OH), поэтому основание двухкислотное.

Вопрос 2

Реакция между кислотой и основанием называется реакцией:

Реакция между кислотой и основанием с образованием соли и воды называется реакцией нейтрализации.

Вопрос 3

При нагревании нерастворимые основания разлагаются на:

Cu(OH)₂ →(t) CuO + H₂O. Нерастворимые основания при нагревании разлагаются на соответствующий оксид металла и воду.

Вопрос 4

Какое основание является щёлочью (растворимым)?

NaOH — растворимое основание (щёлочь). Cu(OH)₂, Fe(OH)₃, Mg(OH)₂ — нерастворимые основания.

Вопрос 5

Нерастворимое основание Cu(OH)₂ можно получить:

Нерастворимые основания получают реакцией обмена: CuSO₄ + 2KOH = Cu(OH)₂↓ + K₂SO₄. Оксид меди с водой не реагирует.

Тест: §25 · Кислоты
Правильных ответов: 0 / 5

Вопрос 1

По основности (числу атомов водорода) фосфорная кислота H₃PO₄ является:

В H₃PO₄ три атома водорода, способных замещаться на металл, — значит кислота трёхосновная.

Вопрос 2

Какой металл НЕ вытесняет водород из раствора соляной кислоты?

Медь Cu стоит в ряду активности ПРАВЕЕ водорода, поэтому не вытесняет его из кислоты. Zn, Mg, Fe — левее H, вытесняют водород.

Вопрос 3

Условие реакции металла с раствором кислоты — металл должен находиться:

Металл вытесняет водород из кислоты, только если стоит левее водорода в ряду активности металлов.

Вопрос 4

Бескислородные кислоты получают:

Бескислородные кислоты (HCl, H₂S) получают синтезом из простых веществ с последующим растворением в воде: H₂ + Cl₂ = 2HCl.

Вопрос 5

Кислоты взаимодействуют с солями, если в результате реакции образуется:

Кислоты реагируют с солями, если образуется осадок или газ. Например: Na₂CO₃ + 2HNO₃ = 2NaNO₃ + H₂O + CO₂↑ (выделяется газ).

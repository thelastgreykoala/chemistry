§9 Химические реакции

Задание 1

Распределите явления на два столбика — физические и химические:
а) образование сосулек на крыше; б) образование чёрного налёта на серебряном изделии; в) брожение виноградного сока; г) испарение воды; д) гашение соды уксусом; е) таяние льда; ж) горение спирта.

Физические: а, г, е (состав вещества не меняется).
Химические: б, в, д, ж (образуются новые вещества с иными свойствами).

Задание 2

Назовите признаки химических реакций, которые можно наблюдать при следующих процессах:
а) горение свечи; б) взаимодействие мела с уксусной кислотой; в) позеленение медной монеты на воздухе; г) растворение медного купороса в воде с добавлением гвоздя.

Признаки: выделение газа ↑, выпадение осадка ↓, изменение цвета, выделение/поглощение теплоты и света.

а) выделение теплоты и света.
б) выделение газа (CO₂↑) и растворение осадка.
в) изменение цвета (зелёный налёт).
г) изменение цвета раствора и появление красного налёта меди на гвозде.

Задание 3

Объясните: почему для тушения пожара перекрывают доступ кислорода? Какое условие протекания реакции горения при этом нарушается?

Реакция горения — взаимодействие горючего вещества с кислородом. Одно из условий — соприкосновение реагентов. При перекрытии доступа кислорода реагенты перестают контактировать, и реакция прекращается.

Задание 4 — экзо/эндо

Определите, экзотермической или эндотермической является реакция:
а) горение природного газа CH₄;
б) разложение известняка при нагревании: CaCO₃ → CaO + CO₂↑;
в) горение магния: 2Mg + O₂ → 2MgO (яркая вспышка);
г) фотосинтез (поглощение солнечного света).

Экзотермические (выделяется теплота): а, в.
Эндотермические (поглощается теплота): б, г.

§10 Химические уравнения

Задание 5

Расставьте коэффициенты:
а) H₂ + O₂ → H₂O
б) Al + O₂ → Al₂O₃
в) Fe + Cl₂ → FeCl₃
г) Na + H₂O → NaOH + H₂↑

Число атомов каждого элемента слева и справа должно быть одинаковым.

а) 2H₂ + O₂ = 2H₂O
б) 4Al + 3O₂ = 2Al₂O₃
в) 2Fe + 3Cl₂ = 2FeCl₃
г) 2Na + 2H₂O = 2NaOH + H₂↑

Расставьте коэффициенты:

г) Al(OH)₃ + HCl → AlCl₃ + H₂O

а) 2Al + 3S = Al₂S₃
б) 2K + 2H₂O = 2KOH + H₂↑
в) Fe₂O₃ + 3H₂ = 2Fe + 3H₂O
г) Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O

а) Fe₂O₃ + 3H₂ = 2Fe + 3H₂O
б) Ca + 2H₂O = Ca(OH)₂ + H₂↑

Задание 8 — найди ошибку

В каких уравнениях ошибка в коэффициентах? Исправьте:
а) 2Na + Cl₂ = NaCl
б) 2H₂ + O₂ = 2H₂O
в) N₂ + H₂ = NH₃
г) CaCO₃ = CaO + CO₂

Ошибки в а) и в).
а) Правильно: 2Na + Cl₂ = 2NaCl.
в) Правильно: N₂ + 3H₂ = 2NH₃.
б) и г) — верны.

§11 Типы химических реакций

Задание 9

Определите тип реакции и расставьте коэффициенты:
а) CuO + H₂SO₄ → CuSO₄ + H₂O
б) NH₄HCO₃ → NH₃↑ + CO₂↑ + H₂O
в) SO₃ + H₂O → H₂SO₄
г) Zn + CuSO₄ → ZnSO₄ + Cu↓

а) CuO + H₂SO₄ = CuSO₄ + H₂O — обмен.
б) NH₄HCO₃ = NH₃↑ + CO₂↑ + H₂O — разложение.
в) SO₃ + H₂O = H₂SO₄ — соединение.
г) Zn + CuSO₄ = ZnSO₄ + Cu↓ — замещение.

Задание 10

Расставьте коэффициенты и определите тип реакции:
а) Mg + HCl → MgCl₂ + H₂↑
б) Fe(OH)₃ → Fe₂O₃ + H₂O
в) BaCl₂ + Na₂SO₄ → BaSO₄↓ + NaCl
г) N₂ + H₂ → NH₃

а) Mg + 2HCl = MgCl₂ + H₂↑ — замещение.
б) 2Fe(OH)₃ = Fe₂O₃ + 3H₂O — разложение.
в) BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl — обмен.
г) N₂ + 3H₂ = 2NH₃ — соединение.

Задание 11 — творческое

Придумайте по одному примеру каждого типа реакции из повседневной жизни или природы. Кратко опишите наблюдаемый признак реакции.

Фотосинтез, ржавление железа, горение газа, нейтрализация кислоты содой — к каким типам они относятся?

Соединение: горение магния — яркая вспышка (2Mg + O₂ = 2MgO).
Разложение: разложение H₂O₂ — выделение пузырьков O₂↑.
Замещение: железный гвоздь в CuSO₄ — красный налёт меди.
Обмен: гашение соды уксусом — выделение CO₂↑.

Вопрос 1

Химическая реакция — это явление, при котором:

Химическая реакция — превращение одних веществ (реагентов) в другие (продукты) с новыми свойствами. Изменение формы или агрегатного состояния — физические явления.

Вопрос 2

Какое из перечисленных явлений — химическое?

Горение фитиля — химическое явление: образуются новые вещества (CO₂, H₂O). Плавление воска, испарение спирта, дробление сахара — физические явления.

Вопрос 3

Признак химической реакции — выпадение осадка. Какой осадок выпадает при взаимодействии хлорида натрия NaCl с нитратом серебра AgNO₃?

NaCl + AgNO₃ → AgCl↓ + NaNO₃. Хлорид серебра AgCl — белый нерастворимый осадок, один из признаков реакции.

Вопрос 4

Реакция горения относится к:

Реакции горения — экзотермические: они протекают с выделением теплоты и часто света. Эндотермические — наоборот, требуют постоянного подвода теплоты.

Вопрос 5

Условие, необходимое для начала большинства химических реакций:

Основное условие — соприкосновение веществ. Именно на этом принципе основан аппарат Киппа: убрав контакт кислоты с цинком, реакцию можно остановить.

Тест: §10 · Химические уравнения
Правильных ответов: 0 / 5

Вопрос 1

Закон сохранения масс означает, что:

Закон Ломоносова–Лавуазье: масса веществ, вступивших в реакцию, равна массе образовавшихся продуктов. Именно поэтому в уравнениях расставляют коэффициенты.

Вопрос 2

Чем отличается схема реакции от уравнения реакции?

Схема реакции показывает направление превращения (→), но не отражает закон сохранения масс. Уравнение со знаком = и расставленными коэффициентами — отражает.

Вопрос 3

Расставьте коэффициенты: Al + O₂ → Al₂O₃. Сумма всех коэффициентов:

4Al + 3O₂ = 2Al₂O₃. Сумма коэффициентов: 4 + 3 + 2 = 9.

Вопрос 4

Коэффициент в химическом уравнении — это цифра, которая стоит:

Коэффициент ставится перед формулой и показывает число молекул (или моль) данного вещества. Индекс — цифра внутри формулы, показывает число атомов в молекуле.

Вопрос 5

Какое уравнение расставлено верно?

2H₂ + O₂ = 2H₂O — верно: слева 4H и 2O, справа тоже 4H и 2O. В а) нужно: H₂ + Cl₂ = 2HCl. В б) — 4Na + O₂ = 2Na₂O. В г) — Fe + S = FeS.

Тест: §11 · Типы химических реакций
Правильных ответов: 0 / 5

Вопрос 1

Реакция соединения — это:

Соединение: A + B → AB. Пример: 4P + 5O₂ = 2P₂O₅ — из фосфора и кислорода образуется одно вещество.

Вопрос 2

Реакция CuSO₄ + Fe = FeSO₄ + Cu относится к типу:

Простое вещество Fe замещает медь Cu в сложном веществе CuSO₄ — реакция замещения. Признак: в реакции участвуют одно простое и одно сложное вещество.

Вопрос 3

К реакциям разложения относится:

2H₂O₂ = 2H₂O + O₂↑ — разложение: из одного вещества образуются несколько. В а) — соединение, в) — замещение, г) — обмен.

Вопрос 4

Катализатор в ходе реакции:

Катализатор ускоряет реакцию, но сам в ней не расходуется. Пример: MnO₂ при разложении H₂O₂ — после реакции оксид марганца остаётся в неизменном количестве.

Вопрос 5

Реакция обмена — это реакция, при которой:

Обмен: AB + CD → AD + CB. Два сложных вещества «меняются» частями. Пример: 2NaOH + H₂SO₄ = Na₂SO₄ + 2H₂O.
